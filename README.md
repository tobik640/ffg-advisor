# FFG Advisor

Repozitář obsahuje projekt FFG Advisor 0.3 v archivu `FFG-Advisor-github-ready.zip`.

## Cloudflare Pages
- Framework preset: None
- Build command: `unzip -o FFG-Advisor-github-ready.zip -d dist`
- Build output directory: `dist/ffg-advisor-github-ready`

Aplikace je statická HTML/CSS/JS PWA. Před ostrým použitím neukládejte osobní ani citlivá klientská data. Výpočty a tržní snapshoty vyžadují odborné ověření.
